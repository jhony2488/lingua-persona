# Tauri bundle resources

This directory is bundled into the app via the `"resources": "./"` map entry in
`tauri.conf.json`, which strips the `resources/` prefix — files land at the root
of the app's resource directory.

At build time the release pipeline copies the Next.js standalone server into
`resources/server/standalone/` — `src-tauri/src/main.rs` then launches it from
`resource_dir/server/standalone/server.js` via the Node sidecar binary.

> Only this file is committed. Everything else here is a build artifact and is
> gitignored (`.next/standalone` is generated by `npm run build:standalone`).
