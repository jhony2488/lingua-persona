# PWA and distribution

LinguaPersona is an installable PWA built with Next.js (Turbopack) and Serwist, with a service worker, manifest, and offline install support.

## Current implementation

### Manifest

The manifest is generated by `src/app/manifest.ts` (App Router) and served at `/manifest.webmanifest`:

- `name`/`short_name`: **LinguaPersona**
- `display: standalone`, `orientation: portrait`
- `theme_color`/`background_color`: `#4f46e5` / `#ffffff`
- Icons in `public/icons/`: `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` (generated by `scripts/generate-icons.mjs`)

### Service worker (Serwist + Turbopack)

The project uses `@serwist/turbopack`, which bundles the service worker at build time (esbuild) and serves it through a Route Handler:

- `src/app/sw.ts` — worker source (Serwist)
- `src/app/serwist/[path]/route.ts` — serves `/serwist/sw.js` and `/serwist/sw.js.map`
- `src/components/pwa/sw-register.tsx` — registers the SW only in production

Cache strategies in `sw.ts`:

- `/api/*` → **NetworkFirst** (5s timeout, offline fallback to cache)
- Navigation (`mode: "navigate"`) → **StaleWhileRevalidate**
- Assets/pages → Serwist `defaultCache` + build precache
- Offline fallback → `/~offline` (`src/app/~offline/page.tsx`)

### Installation

`src/components/pwa/install-banner.tsx` intercepts `beforeinstallprompt` and shows a custom banner. The dismissal is persisted in `localStorage`.

### Notifications

`src/lib/notifications.ts` wraps permission (`Notification.requestPermission`) and push subscription (`pushManager.getSubscription`). Web Push with VAPID is deferred to a later phase.

> **Note**: `output: "export"` is not used — Route Handlers (`/api/*`) require a Node server. To package with Capacitor/Tauri, the API must be hosted separately or embedded.

## Packaging and releases (CI/CD)

Two workflows in `.github/workflows/`:

- `ci.yml` — lint, format:check, tests and build on push/PR to `master`
- `release.yml` — on `v*.*.*` tags: build → package `app-release.pk` (tar.gz of `.next/static`), `app-release.rxe` (zip of `.next`), `SHA256SUMS.txt` → GitHub Release

## Build matrix

| Platform | Technology        | Output                             |
| -------- | ----------------- | ---------------------------------- |
| Web/PWA  | Next.js + Serwist | `.next/` + `app-release.pk`/`.rxe` |
| Android  | Capacitor         | `.apk` / `.aab` (needs API)        |
| iOS      | Capacitor         | `.ipa` (macOS + Xcode, needs API)  |
| Desktop  | Tauri             | `.exe`/`.msi`/`.dmg` (needs API)   |

## Capacitor steps

```bash
npm run build
npx cap sync
npx cap open android   # or ios
```

Then build in Android Studio or Xcode.

## Tauri steps

```bash
npm run tauri build
```

Binaries appear in `src-tauri/target/release`.
